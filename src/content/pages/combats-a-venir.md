Retrouvez les prochains combats confirmés avec leur date, les boxeurs engagés, la catégorie, le lieu et les titres en jeu. Chaque affiche est accompagnée de son enjeu sportif et d'un lien vers l'article détaillé.

Les discussions sans date ferme restent dans le fil d'actualité. Le calendrier est réservé aux rendez-vous suffisamment précis pour être suivis ou préparer un déplacement.

## Ce que l'on retient d'une affiche

La date et la ville situent le rendez-vous. Les deux noms évitent les homonymes. La catégorie évite de comparer des boxeurs qui ne se croiseront pas. Le titre en jeu, quand il existe, dit si la soirée redistribue une ceinture ou si elle prépare la suivante. L'enjeu, en quelques lignes, dit pourquoi ce combat de boxe compte maintenant : un classement, une revanche, une première opportunité nationale, un gala boxe à venir qui concentre plusieurs duels.

Le [calendrier](/calendrier-combats-boxe) reprend les mêmes fiches, rangées dans le temps. Les [galas](/galas-boxe) regroupent les cartes. L'[actualité](/actualites) raconte ce qui bouge avant le jour J : report, signature, blessure.

## Comment une affiche est ajoutée

Elle a une source : fédération, promoteur, club, ou communiqué identifiable. Les noms sont recopiés avec soin, pas de mémoire. Si l'adversaire n'est pas annoncé, le combat n'est pas complété par un nom probable. La page peut rester courte. Elle ne sera pas fausse.

Les comptes rendus, après la soirée, basculent vers les [résultats boxe](/resultats-boxe).
